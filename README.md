  映像の流れ

  1. 惑星の夜明け(0〜16秒):
     夜側に街の明かりが灯る惑星の縁から太陽が昇る。海・大陸・雲・大気の青い縁まで数式で描いています。
  2. 環のある巨大ガス惑星(16〜32秒):
     縞模様の乱流と大赤斑、環に落ちる惑星の影。カメラが環の面をくぐり抜け、裏から透ける環を見上げます。
  3. 渦巻銀河(32〜48秒): 星々の中から上昇して、42万個の星でできた銀河の全体が見えてきます。
  4. 銀河の衝突(48〜64秒): 2つの銀河が、すれ違い、引き戻され、合体します。16万個の星の動きは重力の式を1歩ずつ計算した結
     果で、長い尾が自然に伸びます。
  5. 核への突入(64〜72秒): 合体した銀河の中心へ飛び込み、白い閃光へ。
  6. ブラックホール(72〜100秒): 画素ごとに光の道筋を積分しているので、円盤の裏側が穴の上下にめくれて見えます。近づいてく
     る側が明るく、遠ざかる側が暗いのも計算の結果です。87秒付近では、後ろを通る青い星の光が曲げられて穴の両側に弧として
     現れます(アインシュタインリング)。
  7. 落下(100〜105秒): 事象の地平面へ落ちながら振り返ると、宇宙全体が背後の小さな光の円へ縮んで消えます。理論上そう見え
     るとされる現象です。

  音楽はニ短調で、静かな夜明けから衝突とブラックホールで最大になり、最後は高い一音だけが残る構成です。

    ですが、円盤の色や明るさ、銀河の見た目は映像として整えています。
